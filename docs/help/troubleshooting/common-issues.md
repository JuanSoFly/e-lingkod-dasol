# Common Issues and Solutions

**Help Topic**: Resolving Frequent System Problems  
**Audience**: All Users  
**Difficulty**: Beginner to Intermediate

## Quick Problem Solving

### 🔍 Before You Start

When experiencing issues with the E-Lingkod Dasol HRIS:
1. **Take note of error messages** - Write down exact wording
2. **Check your internet connection** - Ensure stable connectivity  
3. **Try basic solutions first** - Many issues have simple fixes
4. **Document the problem** - Note what you were doing when it occurred

### 🚨 Emergency Issues
If you encounter these problems, contact IT support immediately:
- Cannot access any part of the system
- See other employees' personal information
- System displaying obviously wrong information
- Security warnings or alerts
- Suspected unauthorized access to your account

## 🔐 Login and Authentication Issues

### Problem: Cannot Log In

#### "Invalid username or password" error
**Most Common Causes:**
- Typing error in username or password
- Caps Lock is enabled
- Password has been changed and you're using old one
- Account may be temporarily locked

**Solutions to Try:**
1. **Check Caps Lock** - Ensure it's disabled
2. **Verify Username** - Check exact spelling and format
3. **Retype Password** - Type slowly and carefully
4. **Wait 5 minutes** - Account may be temporarily locked
5. **Use Password Reset** - Click "Forgot Password" if unsure

#### "Account locked" message
**Why This Happens:**
- Multiple failed login attempts
- Security protection against unauthorized access
- Automatic security measure

**How to Resolve:**
1. **Wait 15-30 minutes** - Most locks are temporary
2. **Don't keep trying** - Additional attempts extend the lockout
3. **Contact IT if urgent** - They can unlock your account
4. **Reset password** - Consider if you've forgotten current password

#### Page won't load or keeps timing out
**Possible Causes:**
- Internet connection issues
- Server maintenance
- Browser cache problems
- Network firewall restrictions

**Solutions to Try:**
1. **Check other websites** - Verify internet connectivity
2. **Clear browser cache** - Remove stored temporary files
3. **Try different browser** - Use Chrome, Firefox, or Edge
4. **Restart browser** - Close completely and reopen
5. **Contact IT** - If problem persists for more than 15 minutes

## 🖥️ Display and Performance Issues

### Problem: System Running Slowly

#### Pages take a long time to load
**Normal vs. Concerning:**
- **Normal**: 2-5 seconds for page loading
- **Concerning**: 15+ seconds or pages never fully load

**Speed Improvement Steps:**
1. **Close other browser tabs** - Reduce memory usage
2. **Close unnecessary programs** - Free up computer resources
3. **Check internet speed** - Use speed test website
4. **Clear browser cache** - Remove old temporary files
5. **Restart browser** - Start with fresh session

#### System freezes or becomes unresponsive
**Immediate Actions:**
1. **Wait 30 seconds** - Sometimes system recovers automatically
2. **Don't click repeatedly** - This can make freezing worse
3. **Check for error messages** - Look for any system alerts
4. **Save work if possible** - Before closing browser

**Recovery Steps:**
1. **Close browser tab** - Use X button or Ctrl+W
2. **Restart browser** - Close completely and reopen
3. **Log back in** - May need to redo recent work
4. **Report if frequent** - Contact IT if happens regularly

### Problem: Display Issues

#### Text is too small or too large
**Browser Zoom Solutions:**
1. **Use Ctrl and + keys** - Increase size
2. **Use Ctrl and - keys** - Decrease size
3. **Use Ctrl and 0** - Reset to normal size
4. **Browser menu** - Find zoom options in View menu

#### Missing buttons or menu items
**Possible Causes:**
- Browser zoom level incorrect
- Screen resolution too low
- Browser window too small
- Role-based restrictions (normal security feature)

**Solutions to Try:**
1. **Adjust browser zoom** - Try 100% zoom level
2. **Maximize browser window** - Use full screen
3. **Scroll to see more** - Content may be below visible area
4. **Check your role** - Some functions restricted by user role

#### Colors or layout look wrong
**Quick Fixes:**
1. **Refresh the page** - Press F5 or Ctrl+R
2. **Clear browser cache** - Remove old styling files
3. **Check browser compatibility** - Use supported browsers
4. **Disable browser extensions** - Some extensions interfere with display

## 🔒 Permission and Access Issues

### Problem: "Access Denied" Messages

#### "You don't have permission to access this page"
**This is Normal When:**
- Trying to access other employees' personal information
- Attempting to use administrative functions as an employee
- Accessing reports or analytics not meant for your role

**This Indicates a Problem When:**
- Can't access your own personal information
- Can't perform basic job functions
- Getting errors for previously working features

**What to Do:**
1. **Check if this is expected** - Review what you're trying to access
2. **Verify you're logged in correctly** - Confirm your role and permissions
3. **Try accessing from main menu** - Use proper navigation path
4. **Contact supervisor** - They can clarify if you should have access
5. **Contact IT if needed** - For technical permission issues

#### "Session expired" or forced logout
**Common Causes:**
- 2-hour session timeout for security
- Inactivity period exceeded
- System maintenance or updates

**How to Handle:**
1. **Log back in normally** - Use regular login process
2. **Save work frequently** - Prevent losing progress
3. **Stay active** - Click or move mouse occasionally during long tasks
4. **Use multiple sessions cautiously** - Avoid opening many browser tabs

### Problem: Can't Find Expected Features

#### Menu items or functions missing
**Security Feature (Normal):**
The new privacy protection system hides functions you can't use:
- **Employees see**: Own profile, leave applications, document requests
- **HR Admins see**: All employee management, approvals, reports
- **Super Admins see**: Everything including system administration

**Troubleshooting Missing Features:**
1. **Verify your role** - Check with supervisor about expected access
2. **Try different navigation** - Look for function in different menu
3. **Check help documentation** - Confirm feature exists for your role
4. **Contact HR** - They can clarify what access you should have

## 📄 Data and Form Issues

### Problem: Forms Not Working

#### Can't save or submit forms
**Common Solutions:**
1. **Fill all required fields** - Look for red asterisks (*)
2. **Check data formats** - Dates, phone numbers, email addresses
3. **Remove special characters** - Some fields don't accept symbols
4. **Stay within character limits** - Check maximum length requirements

#### Error messages about data validation
**Field-Specific Issues:**
- **Email**: Must include @ symbol and valid domain
- **Phone**: Use proper format (e.g., 09XX-XXX-XXXX)
- **Dates**: Use system format (usually MM/DD/YYYY)
- **Numbers**: Don't include letters or special characters

#### Lost work when page refreshed
**Prevention:**
- Save work frequently using Save buttons
- Avoid using browser Back button
- Don't refresh page while working on forms
- Copy important text before submitting

**Recovery:**
- Check if auto-save feature preserved work
- Look for draft or temporary saves
- Contact IT if large amount of work lost

### Problem: Data Display Issues

#### Information appears incorrect or outdated
**First Steps:**
1. **Refresh the page** - Press F5 to reload current data
2. **Clear browser cache** - Remove old cached information
3. **Log out and back in** - Reset your session
4. **Check from different device** - Verify if issue is device-specific

**When to Report:**
- Personal information is definitely wrong
- System shows impossible dates or values
- Data that should be updated isn't changing
- Calculations appear incorrect

#### Can't search or filter data properly
**Search Tips:**
1. **Use simple terms** - Start with basic keywords
2. **Check spelling** - Verify search terms are correct
3. **Try partial matches** - Use beginning of words
4. **Use date ranges** - Specify time periods for better results

**Filter Troubleshooting:**
- Clear all filters and start over
- Apply one filter at a time
- Check for conflicting filter combinations
- Verify filter options are available for your role

## 🌐 Browser and Technical Issues

### Problem: Browser Compatibility

#### Website doesn't work in your browser
**Recommended Browsers:**
- **Google Chrome** (latest version)
- **Mozilla Firefox** (latest version)
- **Microsoft Edge** (latest version)
- **Safari** (on Mac, latest version)

**Browser Settings to Check:**
1. **Enable JavaScript** - Required for system functionality
2. **Allow cookies** - Needed for login and session management
3. **Disable popup blockers** - For system notifications and reports
4. **Update browser** - Use most recent version available

#### Browser extensions causing problems
**Troubleshooting Extensions:**
1. **Try incognito/private mode** - Extensions usually disabled
2. **Disable ad blockers** - May block system functionality
3. **Disable privacy extensions** - May interfere with login
4. **Test without extensions** - Identify problematic add-ons

### Problem: Network and Connectivity

#### Intermittent connection issues
**Quick Checks:**
1. **Test other websites** - Verify general internet connectivity
2. **Try wired connection** - If using Wi-Fi, test ethernet cable
3. **Restart router/modem** - Unplug for 30 seconds, plug back in
4. **Contact network administrator** - For workplace network issues

#### VPN or firewall blocking access
**Common Symptoms:**
- Can access other sites but not HRIS
- Connection times out
- Security certificate errors
- Some features work but others don't

**Solutions:**
1. **Contact IT administrator** - They may need to whitelist the system
2. **Try different network** - Test from mobile hotspot if allowed
3. **Disable VPN temporarily** - If using personal VPN
4. **Check company firewall** - May need system added to allowed list

## 📱 Mobile and Remote Access Issues

### Problem: Mobile Device Issues

#### System doesn't work well on phone or tablet
**Current Status:**
The HRIS is optimized for desktop/laptop use but has basic mobile support

**Mobile Best Practices:**
1. **Use landscape mode** - Rotate device for better view
2. **Use mobile browser** - Chrome or Safari work best
3. **Zoom appropriately** - Adjust for readability
4. **Limit complex tasks** - Use desktop for detailed work

#### Touch screen not responding properly
**Solutions:**
1. **Clean screen** - Remove dirt or moisture
2. **Remove screen protector temporarily** - Test if it's causing issues
3. **Restart device** - Clear temporary glitches
4. **Use desktop version** - For important or urgent tasks

### Problem: Remote Access

#### Can't access system from home
**Security Considerations:**
1. **Check if remote access is allowed** - Policy may restrict home use
2. **Use secure network** - Avoid public Wi-Fi
3. **Contact IT for VPN setup** - May need special configuration
4. **Verify you have authorization** - Supervisor approval may be required

## 🆘 When to Contact Support

### Self-Service First

#### Try These Solutions Before Calling:
- Refresh the page (F5)
- Clear browser cache and cookies
- Log out and log back in
- Try a different browser
- Restart your computer
- Check internet connection

### Contact Support When:

#### Immediate Support Needed (Call/Email Right Away)
- Security alerts or suspicious activity
- Can see other employees' personal information
- System showing obviously wrong data
- Cannot access system for urgent work needs
- Receiving error messages about privacy violations

#### Standard Support Request (Email)
- Persistent technical issues after trying basic solutions
- Questions about permissions or access levels
- Problems with specific features or functions
- Need help with complex tasks or procedures

#### Information for Support
Always provide:
1. **Your name and employee number**
2. **Exact error message** (screenshot if possible)
3. **What you were trying to do**
4. **When the problem started**
5. **Steps you've already tried**
6. **Browser and device information**
