## Password Requirements

The E-Lingkod Dasol HRIS requires strong passwords to protect your account and personal information. Understanding and following these requirements is essential for system security.

### 🔒 Minimum Requirements

Your password must include:
- **At least 8 characters** (no maximum limit)
- **One uppercase letter** (A-Z)
- **One lowercase letter** (a-z)
- **One number** (0-9)
- **One special character** (@, $, !, %, *, ?, &)

### ✅ Good Password Examples
- `MyWork2025!` ✅ (12 characters, meets all requirements)
- `Dasol#Employee99` ✅ (15 characters, very secure)
- `SecurePass@2025` ✅ (15 characters, excellent)
- `HRteam!Strong8` ✅ (14 characters, very good)

### ❌ Poor Password Examples
- `password123` ❌ (too simple, no uppercase or special characters)
- `dasol2025` ❌ (no uppercase or special characters)
- `PASSWORD` ❌ (no numbers, lowercase, or special characters)
- `12345678` ❌ (only numbers, no letters or special characters)

## 🎯 Creating Strong Passwords

### Password Creation Strategies

#### Method 1: Passphrase Approach
Create a memorable phrase and modify it:
1. **Start with a phrase**: "I work for Dasol government since 2020"
2. **Take first letters**: "IwfDgs2020"
3. **Add complexity**: "IwfDgs2020!"
4. **Result**: `IwfDgs2020!` (meets all requirements)

#### Method 2: Meaningful Substitution
Use a meaningful phrase with character substitutions:
1. **Start with phrase**: "Secure Employee Account"
2. **Make substitutions**: "S3cur3 Empl0y33 @cc0unt"
3. **Remove spaces**: "S3cur3Empl0y33@cc0unt"
4. **Result**: `S3cur3Empl0y33@cc0unt` (very secure)

#### Method 3: Memorable Pattern
Create a pattern that's meaningful to you:
1. **Personal reference**: Your favorite place + year + symbol
2. **Example**: "Bolinao" + "2025" + "!#"
3. **Result**: `Bolinao2025!#` (secure and memorable)

### Password Strength Checking

#### Strong Password Indicators
- **12+ characters**: Longer passwords are significantly more secure
- **Character variety**: Mix of uppercase, lowercase, numbers, symbols
- **Unpredictable**: Not based on dictionary words or personal information
- **Unique**: Different from passwords used elsewhere

#### Weak Password Patterns to Avoid
- **Dictionary words**: Even with number substitutions
- **Personal information**: Names, birthdays, employee numbers
- **Common patterns**: Sequential numbers or letters
- **Repeated characters**: Multiple same characters in a row

## 🔐 Password Management Best Practices

### Protecting Your Password

#### Never Share Your Password
- **With colleagues**: Even trusted coworkers should not know your password
- **With supervisors**: Legitimate requests will never ask for your password
- **With IT support**: Real support will reset, not ask for existing passwords
- **With family**: Keep work passwords completely private

#### Secure Storage Guidelines
- **Don't write it down**: Avoid paper notes or unsecured digital files
- **Don't save in browsers**: Especially on shared computers
- **Use secure methods**: Consider approved password managers if allowed
- **Keep it mental**: Memorize your password for best security

#### Recognizing Password Scams
- **Phishing emails**: Never enter your password from email links
- **Fake websites**: Always verify you're on the correct login page
- **Phone requests**: IT will never call asking for passwords
- **Social engineering**: Be suspicious of urgent password requests

### When to Change Your Password

#### Immediate Changes Required
- **Suspected compromise**: If you think someone knows your password
- **Security alerts**: System notifications about unusual activity
- **Shared accidentally**: If you accidentally disclosed your password
- **Phishing attempts**: If you entered password on a fake site

#### Regular Changes Recommended
- **Every 6 months**: Proactive security measure
- **After security incidents**: System-wide password updates
- **Role changes**: When your job responsibilities change
- **Following best practices**: Align with organizational policies

## 🚪 Secure Login Procedures

### Step-by-Step Login Process

#### 1. Verify the Website
- **Check URL**: Ensure you're on the correct government website
- **Look for HTTPS**: Verify the lock icon in your browser
- **Bookmark login page**: Use bookmarks instead of searching
- **Avoid public computers**: Never login from public or shared computers

#### 2. Enter Credentials Securely
- **Type carefully**: Double-check username and password
- **Use private browsing**: Consider incognito/private mode
- **Check for shoulder surfing**: Ensure no one is watching
- **Clear autofill**: Don't rely on browser password saving

#### 3. Complete Login Process
- **Wait for confirmation**: Ensure login is successful
- **Check session information**: Verify your role and permissions
- **Note any security alerts**: Pay attention to system messages
- **Begin work safely**: Proceed with authorized activities only

### Login Security Features

#### System Security Indicators
- **🔒 HTTPS Connection**: Encrypted communication
- **⏱️ Session Timer**: Shows remaining active time
- **🚨 Security Alerts**: Warnings about unusual activity
- **📍 Location Tracking**: Notifications for new locations
- **📱 Device Recognition**: Alerts for unrecognized devices

#### Failed Login Protection
- **Account Lockout**: Temporary lockout after multiple failed attempts
- **Security Delays**: Increasing delays between login attempts
- **Administrator Alerts**: IT notification of repeated failures
- **Recovery Options**: Secure password reset procedures

## 🔄 Password Reset Procedures

### When You Need to Reset

#### Forgotten Password
1. **Use "Forgot Password" link**: On the login page
2. **Enter your email address**: Must match account email
3. **Check your email**: Look for reset instructions
4. **Follow secure link**: Click only on official reset links
5. **Create new password**: Must meet all requirements

#### Compromised Password
1. **Contact IT immediately**: Don't wait to reset
2. **Change password**: Use emergency reset if available
3. **Review account activity**: Check for unauthorized access
4. **Monitor closely**: Watch for unusual activity after reset

### Reset Process Security

#### Email Security
- **Official email only**: Reset links sent to registered email address
- **Time limits**: Reset links expire after limited time
- **One-time use**: Reset links can only be used once
- **Secure transmission**: All reset communications encrypted

#### Verification Steps
- **Identity confirmation**: May require additional verification
- **Security questions**: Backup verification methods
- **Account recovery**: Additional steps for high-risk situations
- **Documentation**: All reset activities logged for audit

## ⚠️ Common Password Mistakes

### Technical Mistakes

#### Browser-Related Issues
- **Caps Lock**: Check if Caps Lock is accidentally enabled
- **Auto-correct**: Disable auto-correct for password fields
- **Copy/paste**: Be careful with copying passwords
- **Browser caching**: Clear cache if experiencing issues

#### Typing Errors
- **Similar characters**: Distinguish between 0/O, 1/l, etc.
- **Extra spaces**: Avoid spaces before or after password
- **Special characters**: Ensure special characters are correct
- **Case sensitivity**: Remember uppercase/lowercase distinctions

### Security Mistakes

#### Predictable Passwords
- **Sequential patterns**: Avoid 123, abc, qwerty patterns
- **Date patterns**: Don't use birthdays or anniversaries
- **Name variations**: Avoid using names with number substitutions
- **Common substitutions**: Avoid @ for a, 3 for e, etc.

#### Password Reuse
- **Same password everywhere**: Each account should have unique password
- **Slight variations**: Don't just add numbers to existing passwords
- **Work vs. personal**: Keep work passwords completely separate
- **Old passwords**: Don't reuse previous passwords

## 🛠️ Troubleshooting Password Issues

### Common Problems and Solutions

#### "Password doesn't meet requirements"
**Check each requirement:**
- ✓ At least 8 characters
- ✓ One uppercase letter
- ✓ One lowercase letter  
- ✓ One number
- ✓ One special character (@$!%*?&)

#### "Account locked due to failed login attempts"
**Resolution steps:**
1. Wait for automatic unlock (usually 15-30 minutes)
2. Contact IT support if urgent access needed
3. Verify you're using correct username and password
4. Consider password reset if you're unsure of current password

#### "Password expired" message
**Next steps:**
1. Follow prompted password change process
2. Create new password meeting all requirements
3. Ensure new password is different from recent passwords
4. Test new password on first login

#### Can't receive password reset email
**Troubleshooting:**
1. Check spam/junk folders in email
2. Verify email address associated with account
3. Wait a few minutes for email delivery
4. Contact IT support if email doesn't arrive

- [ ] Never share your password with anyone
