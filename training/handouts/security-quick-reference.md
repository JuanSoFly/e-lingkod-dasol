## 🔐 Password Security

### Requirements
- **8+ characters** minimum
- **Uppercase letter** (A-Z)
- **Lowercase letter** (a-z)
- **Number** (0-9)
- **Special character** (@$!%*?&)

### Good Examples
- `MyWork2025!`
- `Dasol#Employee99` 
- `SecurePass@2025`

### Never Do
- ❌ Share your password
- ❌ Write it down
- ❌ Use same password elsewhere
- ❌ Use personal information

---

## 🎯 What You Can Access

### ✅ Your Information Only
- Personal profile and contact details
- Your leave applications and balances
- Your document requests and certificates
- Your performance evaluations and goals
- Your training records and history

### ❌ Cannot Access
- Other employees' personal information
- Colleagues' leave records or applications
- System-wide reports and analytics
- Administrative functions and controls
- HR management and configuration

---

## 🚨 Security Violations - Report Immediately

### Privacy Violations
- Seeing other employees' personal data
- Access to unauthorized information
- System displaying wrong data
- Unusual security warnings

### Security Issues
- Suspicious login attempts
- Unexpected system behavior
- Error messages about privacy
- Requests for your password

### Social Engineering
- Calls asking for passwords
- Emails requesting login credentials
- Urgent requests to bypass security
- Impersonation of IT/HR staff

## 🛡️ Safe System Usage

### Login Security
1. ✅ Verify correct website URL
2. ✅ Look for HTTPS lock icon
3. ✅ Type password carefully
4. ✅ Never save on shared computers

### During Session
1. ✅ Access only your own data
2. ✅ Don't share screen with sensitive info
3. ✅ Report unusual system behavior
4. ✅ Stay within authorized functions

### Logout Security
1. ✅ Click "Logout" button
2. ✅ Close browser tab completely
3. ✅ Clear cache on shared computers
4. ✅ Lock workstation when away

---

## ⚠️ Red Flags - Call for Help

### Immediate Dangers
🚨 **Seeing colleague's personal data**
🚨 **System showing obviously wrong info**
🚨 **Security alerts or warnings**
🚨 **Unusual access to admin functions**

### Suspicious Activity
⚠️ **Unexpected error messages**
⚠️ **Slow system performance**
⚠️ **Login notifications for wrong times**
⚠️ **Colleagues asking for password help**

## 📋 Your Privacy Rights

### Right to Access
- View all your personal data
- Request copies of 201 files
- Understand data processing

### Right to Correct
- Update contact information
- Fix inaccurate personal data
- Request HR review for changes

### Right to Object
- Limit non-essential data use
- Object to automated decisions
- Restrict certain data sharing

### How to Exercise Rights
1. Use self-service features in system
2. Contact HR for complex requests
3. Submit written requests with ID
4. Expect response within 15 working days

## 📱 Mobile and Remote Access

### Security Requirements
- ✅ Use secure networks only
- ✅ Avoid public Wi-Fi
- ✅ Log out completely when finished
- ✅ Don't save passwords on mobile

### What's Not Allowed
- ❌ Public computer access
- ❌ Sharing login with family
- ❌ Unsecured network connections
- ❌ Screenshots of sensitive data

## 💡 Best Practices

### Password Management
- Change immediately if compromised
- Use unique password for work system
- Don't write down or save passwords
- Enable screen lock on devices

### Data Protection
- Verify you're viewing your own data
- Don't attempt unauthorized access
- Report accidental data exposure
- Respect colleagues' privacy

### Incident Response
- Report issues immediately
- Document what you observed
- Don't investigate on your own
- Follow up to ensure resolution
